# ADR-0015: Generated API types and a frontend adapter layer

## Status

Proposed | **Accepted** | Rejected | Superseded | Deprecated

## Context

The backend publishes its HTTP contract as OpenAPI, generated by FastAPI from the routes
and Pydantic schemas (`/openapi.json`). The frontend declares its own types by hand.

The two have already drifted before a single request has been made: the assistant's
`Message.id` is `string` on the frontend and an integer on the wire, `Message.mode` is
missing although AC-016 requires the mode to be visible, and `Conversation.provider` exists
only on the frontend. Nothing fails today because the panel renders fixtures. It will fail
the day it calls the API, and only at runtime.

Constraints:

- **CON-001**: The backend is the source of truth for wire shapes. A second hand-written
  copy is a second place to update and a guaranteed source of drift.
- **CON-002**: Wire shapes are not the shapes components want. Ids, dates, nesting and
  naming differ, and the backend will change them for its own reasons.
- **CON-003**: [docs/folder-structure.md](../folder-structure.md) already gives each domain
  an `api/` folder (endpoints, query hooks) and a `model/` folder (types the domain owns),
  and says the client models only what the server does not decide.
- **CON-004**: Stream events are already typed by `@ag-ui/core`
  ([ADR-0009](adr-0009-ag-ui-protocol.md) IMP-002). OpenAPI cannot describe an SSE
  stream's events anyway.
- **CON-005**: React re-renders on reference change, TanStack Query shares structure only
  for plain objects and arrays, and cached or persisted data loses class prototypes. Data
  the UI holds must be plain and immutable.

## Decision

**Generate wire types from the backend's OpenAPI document, and translate them to frontend
models in a per-domain adapter layer. Wire types never leave `api/`.**

1. **One contract file, committed.** A backend script writes `openapi.json` from the app
   object, with no server running. `openapi-typescript` turns it into
   `frontend/src/lib/api/schema.d.ts`. Both files are committed and regenerated by script.
2. **A typed fetch client.** `openapi-fetch` in `lib/api/` checks paths, parameters, bodies
   and responses against the schema. It adds types, not structure.
3. **Adapters per domain.** `domains/<ctx>/api/adapters.ts` holds pure functions:
   `toX(dto) → model` for responses, and `toXBody(model) → dto` where a request needs
   reshaping. Endpoints speak DTOs; hooks return models; components see only models.
4. **Plain data, pure functions.** Models are immutable plain types. Adapters are
   functions, not classes. Classes are kept for infrastructure with lifecycle (an SSE
   reader, an error type).
5. **Enforced, not conventional.** A lint rule forbids importing `lib/api/schema` or a DTO
   type outside `domains/*/api/` and `lib/api/`. CI regenerates both contract files and
   fails if they differ from what is committed.

```
backend routes + Pydantic ──► openapi.json ──► lib/api/schema.d.ts (DTOs)
                                                     │
                     domains/<ctx>/api/endpoints.ts  │ DTO in, DTO out
                     domains/<ctx>/api/adapters.ts   ▼ DTO ⇄ model
                     domains/<ctx>/api/use*.ts       model out
                                                     │
                     domains/<ctx>/components/       model only
```

## Consequences

### Positive

- **POS-001**: A backend change that breaks the frontend fails the PR that made it, at
  build time, instead of in the browser.
- **POS-002**: A backend rename touches one adapter function, not every component that
  shows the field.
- **POS-003**: Adapters are pure functions over plain data, so they are trivially unit
  tested and safe for TanStack Query's structural sharing.
- **POS-004**: `/docs`, `openapi.json` and the frontend types are one contract, not three
  that can disagree.

### Negative

- **NEG-001**: A mapping layer is code to write even where DTO and model are nearly the
  same. Accept a near-identity adapter rather than letting a DTO leak; it is the seam that
  absorbs the next change.
- **NEG-002**: Every backend contract change needs a regeneration step. CI catches a
  forgotten one, but it is one more thing a contributor must know.
- **NEG-003**: The hand-written [api-contract.md](../api-contract.md) and the generated
  contract can still disagree. The generated one is what runs; api-contract.md stays the
  plan for endpoints not yet built.
- **NEG-004**: Stream events are outside this mechanism (CON-004) and rely on
  `@ag-ui/core` matching what the backend emits, covered by ADR-0009 IMP-007's test.

## Alternatives Considered

### Keep hand-written types

- **ALT-001**: **Description**: The frontend continues to declare API shapes manually.
- **ALT-002**: **Rejection Reason**: Fails CON-001. The drift in the Context section
  happened before any request was made.

### Full client generation (orval, hey-api)

- **ALT-003**: **Description**: Generate a complete client including TanStack Query hooks.
- **ALT-004**: **Rejection Reason**: Saves typing but decides the shape of each domain's
  `api/` folder and puts generated hooks where adapters belong (CON-003). Types-only
  generation leaves structure to the domain.

### Use DTOs as the frontend model

- **ALT-005**: **Description**: Components consume generated types directly; no adapters.
- **ALT-006**: **Rejection Reason**: Fails CON-002. Every wire change ripples into
  components, and wire conventions (integer ids, ISO strings) leak into rendering code.

### Class-based models with mapping methods

- **ALT-007**: **Description**: `Message.fromDto(dto)` and instance methods on model classes.
- **ALT-008**: **Rejection Reason**: Fails CON-005. Instances defeat structural sharing,
  invite in-place mutation React cannot see, and lose their prototype when cached.

## Implementation Notes

- **IMP-001**: First use is the assistant domain, in
  [#27](https://github.com/PiotrMieszczak/dm_assistant/issues/27).
- **IMP-002**: Name the file `adapters.ts`, one per domain `api/` folder. Split by entity
  only when it grows past readability.
- **IMP-003**: Adapters translate shape and type (ids, dates, nesting, names). They do not
  re-validate what the server decides (folder-structure.md, "How much tactical DDD").
- **IMP-004**: Export only models and hooks from a domain's `index.ts`; never a DTO.
- **IMP-005**: The README claimed `eslint-plugin-boundaries` enforces the frontend import
  rules. It is not installed; the frontend has `oxlint` with no boundary rules. The rule in
  Decision 5 is the first enforced one, and the claim is corrected alongside this record.
- **IMP-006**: Revisit trigger — if the frontend gains a second backend, or the API moves
  to a protocol OpenAPI does not describe.
